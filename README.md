# Ashok Kumar Chadha, Architect

Portfolio site for Ashok Kumar Chadha, architect and lighting specialist.

A single static page with no build step: `index.html`, images in `img/`, and Netlify settings in `netlify.toml`.

## Contents

- Introduction with portrait and key figures
- Selected work: 15 projects with photo galleries and credits
- Career milestones and the full project record from his CV
- Approach: principles for the sustainable house, light, and interiors and the plan, with three interactive diagrams
- Commissions: six fixed-scope services
- Enquiry form, handled by Netlify Forms

## Editing

Projects live in the `PROJECTS` list near the end of `index.html`. The full project record is the `D` list. Add images to `img/` and reference them by file name without the extension.

## Deploying

Netlify serves the repository root. Pushing to `main` redeploys the site. Enquiries appear under Forms in the Netlify dashboard; set an email notification there to receive them in an inbox.

## Image rights

Photographs and drawings come from the sources listed in the credits on the page. Images other than Wikimedia Commons and the family portrait need permission from their owners.
